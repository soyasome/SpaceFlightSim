操作方法

マウス機首の上下・左右（仮想スティック）
Q / Eロール
W / Sスロットル 上げ / 下げ（逆噴射まで）
Xスロットル 0
A / D ・ R / F左右 ・ 上下スラスター
Shiftブースト
J巡航モード ON / OFF（天体から遠いほど高速。恒星間も飛べる）
M星図（行き先を選ぶ）
B行き先を切り替え（今の星系の天体を近い順に）
Kジャンプ（行き先が別の恒星のとき）
左クリック機関砲
Spaceミサイル（ロックオン後）
T / Y的を選ぶ（機首に近い敵 / 次の敵）
N敵の増援を呼ぶ
G着陸装置 出す / しまう
Hホバー（垂直離着陸）ON / OFF
Zフライトアシスト ON / OFF
V視点切り替え（コックピット / 追従）
右ドラッグ見回す
C / 中クリックマウススティックを中央に戻す
Iマウス上下の反転
矢印キー機首（マウスの代わり）
Tab / Escこのメニュー（一時停止）

大気中: スロットルは推力になり、翼の揚力で飛びます（失速 約70 m/s）。H のホバー中はスロットルが目標速度になり、R/F で上昇・下降、手を離すと空中で止まります。着陸は G で脚を出し、降下率 7 m/s 以下で接地。

戦闘: 的を機首から25°以内に捉え続けるとロックオン。緑の丸（見越し点）に十字を重ねて撃つと当たります。シールドは4秒被弾しなければ回復、機体（HULL）とミサイルは着陸して数秒止まると回復します。

ゲームパッド: 左スティック=ロール/ピッチ、右スティック=ヨー/上下、RT/LT=スロットル、A=ブースト、X=アシスト、Y=視点、B=着陸装置、LB=ホバー、RB=機関砲、左スティック押し込み=的、右スティック押し込み=ミサイル
