# STARWAKE 仕様書

STARWAKE が「何を、どういう規則と数値で動かしているか」をまとめた、開発する人 (自分と Claude) 向けの文書。

- 遊び方と画面の見方は操作マニュアル (`docs/manual.md`)、アルゴリズムの解説は技術解説 (`docs/index.html`) を見る。
- 大きな機能の設計の経緯は、機能ごとの設計書 (例: `docs/design-oneill-cylinder.md`) にある。
- 数値には `ファイル:行` を添えた。行番号は書いた時点 (コミット `13ecb15` の時点) のもので、コードを変えるとずれる。
  定数の名前でも探せるようにしてある。**正しいのはいつもコードの方**。

---

## 1. 概要と用語

STARWAKE はブラウザで動く宇宙フライトシミュレーター。6自由度の飛行、惑星への着陸、戦闘、自動で作られる無限の銀河を持つ。
ビルドは不要で、素の ES モジュールと Three.js (CDN の importmap で `three@0.170.0`、`index.html` と `tests.html`) だけで動く。

| 用語 | 意味 |
|---|---|
| 銀河座標 | 銀河全体の座標。単位は光年。恒星の位置 (`star.pos`) はこれで持つ |
| 星系座標 | 今の恒星の中心が原点。単位は m。天体の位置 (`def.position`) はこれで持つ |
| 世界座標 | 機体を動かす慣性系。原点 `game.origin` (星系座標) を機体に合わせて動かす |
| フレーム / 座標系 | `game.frame`。機体が今属している天体の座標系 (惑星ローカル座標、円筒ローカル座標)。宇宙では `null` |
| 描画座標 | フレーム座標からカメラ位置を引いたもの。GPU に渡す直前に作る |
| 窓口 | フレームが持つべき関数の組 (`upAt`, `heightAbove` など。4.4節) |
| 区画 (セクター) | 銀河を一辺 10 光年で区切った箱。恒星はこの単位で作る |
| 哨戒隊 (zone) | 星系ごとに決まった場所で待つ敵の組 |
| 窓の帯・陸の帯 | オニール・シリンダーの内壁を周方向に6等分した帯 |

## 2. システム構成

### 2.1 起動の流れ
`index.html` → `src/main.js` が `Game` (`src/game.js`) を作って `start()` し、メニュー (`src/ui/menu.js`)・星図
(`src/ui/starmap.js`)・デバッグ用の `window.debug` をつなぐ。`Game` が物理・宇宙・座標系・描画・HUD を1か所で回す。

| `src/universe` | 銀河 (`galaxy.js`)、星系 (`system.js`)、ダイソン・スウォーム (`swarm.js`)、オニール・シリンダーの形と当たり判定 (`habitat.js`) と中の地形 (`habitatTerrain.js`) | **使わない** |

### 2.3 依存の規則
- `src/universe/` と `src/terrain/` は three.js にも DOM にも依存しない。テストから直接呼べるようにするためと、
  `src/terrain/` は Web Worker からも読み込むため (`src/terrain/noise.js:1-2`, `src/terrain/chunkBuilder.js:2`)。
- 「どこに何があるか」を決める純粋な関数と、それを描く three.js のクラスを分ける。当たり判定は前者を使うので、
  見た目と当たり判定が一致する。

### 2.4 外部とのつながり
- Three.js `0.170.0` を CDN から読む。ネット接続が必要。
- 開発用サーバーは2通り。どちらもポート 5173 で、キャッシュを無効にする。
  - `serve.py` (Python)。`.js` を必ず `text/javascript` で返す (`serve.py:3-6`)。
  - `npx --yes http-server@14.1.1 . -p 5173 -a 127.0.0.1 -c-1 -s` (Node.js)。アプリのプレビューはこちら (`.claude/launch.json`)。
- 保存するのは設定だけ (11章)。宇宙は毎回同じ手順で作り直すので保存しない。

## 3. 実行モデル

### 3.1 時間の進め方
`src/core/loop.js` の `Loop`。

- 物理は **120 Hz の固定ステップ** (`src/game.js:225`)。1フレームの経過時間は 0.1 秒で打ち切る (`src/core/loop.js:26`)。
- 1フレームの中の順番: `beginFrame(dt)` (入力の更新) → `step(h)` を溜まった分だけ → `frame(alpha, dt)` (描画)。
  `alpha` は前後の物理状態の補間に使う (`src/physics/body.js:81-82` の `getInterpolated`)。
- 挙動を変える処理はすべて `step` に置く。こうすると挙動がフレームレートに依存せず、同じ入力なら結果が完全に一致する (M1 のテスト)。
- 敵の判断は 6 ステップに1回 (毎秒 20 回) (`src/combat/combat.js:11`)。弾と地形・小惑星の判定も 6 ステップに1回 (`src/combat/projectiles.js:4`)。

### 3.2 `Game.step(h)` の中身 (`src/game.js:264-336`)
1. 惑星とシリンダーの回転を進める。
2. 機体を失っている間は、復帰までの時間を減らし、戦闘だけ進めて終わる。
3. シリンダーの中なら巡航を止める。巡航の倍率を求める (6.7節)。
4. 重力と空気を求める (`envAt`)。3本の脚が接地してから 0.6 秒は「地上」とみなす (`src/game.js:292`)。
5. 機体に力をかける (`Ship.applyForces`) → 接地 (`GroundContact.apply`) → G の計算 → 積分 → 静止摩擦。
6. 接地の損傷、シールドとエネルギーの回復、戦闘、座標系の切り替え (`_updateFrame`)、宇宙の更新 (`_updateUniverse`)。
7. `HULL` が 0 以下なら機体を失う。

### 3.3 ゲームの状態
| 状態 | 入る | 出る | 間の振る舞い |
|---|---|---|---|
| メニュー | 起動時、`Tab`、マウスの固定が外れたとき (`src/ui/menu.js:31-33`) | 「クリックして開始」、`Tab`、`Esc` | `game.paused = true`。入力も物理も止まる |
| 星図 | `M` (メニュー表示中は開かない) | `M`、`Esc`、閉じるボタン | 一時停止 (`src/ui/starmap.js:38-60`) |
| 機体喪失 | `HULL` ≤ 0 (`src/game.js:777-793`) | 3.5 秒後 (`src/game.js:28`) | 敵と弾は動き続ける。復帰の場所は 7.6節 |
| ジャンプ充填 | `K` (行き先が別の恒星で、宇宙にいるとき) | 4 秒後にジャンプ (`src/game.js:32`)。`K` の再押し・行き先の変更・座標系に入る・機体喪失で中止 | — |
| ジャンプ到着 | ジャンプした瞬間 | 1.5 秒後 (`src/game.js:33`) | 閃光が消えていく |
| 巡航 | `J` (地上では不可、`src/game.js:177`) | `J` で減速を始め、2.5 秒で終わる | 重力と空気を無視 (6.7節) |
| 入港中 | シリンダーの入港口の筒に入る | 筒の外の端を抜ける | 安全地帯 (5.7節) |

## 4. 座標系と単位

### 4.1 単位
長さは m、時間は秒、質量は kg、角度は rad (UI と調整値の一部は度)。銀河座標だけ光年。
定数: 1 光年 = 9.4607e15 m、1 天文単位 = 1.496e11 m、太陽半径 = 6.96e8 m (`src/universe/galaxy.js:8-14`)。

### 4.2 精度
物理の座標は JS の Number (倍精度) のまま扱う。float32 になるのは GPU に送る瞬間だけで、その前にカメラ位置を引く
(Floating Origin、`src/physics/body.js:3-5`)。

### 4.3 座標の段
1. **銀河座標** (光年)。機体の銀河座標 `game.galPos` は、今の恒星の位置 + 星系座標 ÷ 光年。
2. **星系座標** (m)。今の恒星が原点。
3. **世界座標** (m)。宇宙では機体はここで動く。
   - 機体が原点から 1e7 m 離れたら、原点を機体の位置へ移す (`src/game.js:30` の `RECENTER`、`src/game.js:504-512`)。
   - 30 ステップごとに、恒星から 0.2 光年より遠ければ最寄りの恒星を調べ、今の恒星より 5% 以上近い恒星があれば
     その星系に乗り換える (`src/game.js:601-604`)。
4. **フレーム座標**。天体に近づくと機体をその天体の座標系に入れる (`Game.setFrame`、`src/game.js:742-769`)。
   - 惑星: 中心から半径の 6 倍で入り、6.6 倍で出る (`src/universe/system.js:41-42` の `FRAME_ENTER` / `FRAME_EXIT`)。
     惑星ローカル座標は自転と一緒に回る。入るとき・出るときに速度を変換する (`src/physics/frame.js`)。
     ゲーム用の惑星では遠心力とコリオリ力を省いている。実寸の惑星 (`def.fictitious`) では `fictitiousAccel` で重力に足す
     (`src/physics/frame.js`、`Game.envAt`)。自機と敵機に効く (弾にはもともと重力がない)。
   - 実寸では衛星が親の座標系の中にあることがある (IO、PHOBOS。`insideParentFrame`)。親の座標系にいる間も衛星の `entersAt` を調べ、
     入っていれば世界座標を経由して衛星の座標系に乗り換える。衛星の表面までの距離でも巡航を抑える。衛星から出ると宇宙に戻り、
     次のステップで親の座標系に入り直す (`Game._updateFrame`)。両方に入れる所では小さい方 (衛星) を選ぶ。
   - オニール・シリンダー: 入港口の筒の中に入ると入り、筒の外の端を抜けると出る (`src/render/habitat.js:359-367`)。
     円筒ローカル座標は回らない。
   - 座標系が切り替わると、敵と弾はいったん片付ける (`src/combat/combat.js:301-304`)。
5. **描画座標**。フレーム座標からカメラ位置を引いたもの。

### 4.4 座標系の窓口
接地 (`src/flight/ground.js`)、飛行と HUD (`src/game.js`)、敵の操縦 (`src/combat/`) は「下 = 惑星の中心の方」を自分では仮定せず、
`game.frame` の次の関数だけを使う。引数の点は (world と書いたもの以外は) その座標系のローカル座標。

| 窓口 | 意味 | 惑星 (`src/planet/planet.js`) | シリンダー (`src/render/habitat.js`) |
|---|---|---|---|
| `entersAt(world)` | ここで座標系に入るか | 中心から 6R 以内 (`:188`) | 入港口の筒の中 (`:359`) |
| `containsLocal(p)` | まだ中にいるか | 中心から 6.6R 以内 (`:193`) | 中、または筒の中 (`:365`) |
| `surfaceDistance(world)` | 表面までの距離 (巡航・最寄りの天体) | 中心からの距離 − R (`:198`) | 外壁までの距離 (`:370`) |
| `upAt(p, out)` | 真上の向き | 中心から外向き (`:203`) | 軸の方 (`:376`) |
| `heightAbove(p)` | 真下の地面からの高さ | 地形・水面・ビルの屋上を含む (`:208`) | 内壁の地形から (`:381`) |
| `roughHeightAbove(p)` | 軽い版 (敵の操縦用) | 細部とビルを省く (`:213`) | `heightAbove` と同じ (`:385`) |
| `seaLevelAt(p)` | 基準面からの高さ | 中心からの距離 − R (`:220`) | R − 軸からの距離 (`:390`) |
| `gravityAt(p, out)` | 重力加速度 (ベクトル) | 中心向き、g·(R/r)² (`:170-172`, `:225`) | 軸から外向き、g·r/R (`:395`) |
| `airDensityAt(p)` | 空気の密度 (kg/m³) | 高度による指数関数 (`:176-179`, `:231`) | 5.7節 (`:399`) |
| `surfacePoint(dir, alt, out)` | 地面から alt 上の点 | (`:236`) | (`:404`) |

座標系によっては、次の追加の性質を持つ。

| 性質 | 持つもの | 使われ方 |
|---|---|---|
| `gas` | ガス巨星 | 降りられない、深い所でつぶされる、復帰の高さ |
| `safe` | シリンダー (`src/render/habitat.js:119`) | 巡航できない、増援を呼べない、HUD を中向けにする |
| `freeze()` / `unfreeze(t)` | シリンダー | 中にいる間は外の見た目の回転を止める (`src/game.js:758-768`) |
| `wallContact(p, margin)` | シリンダー | 両端の蓋との当たり判定 |
| `spaceport` | シリンダー | 行き先と復帰の場所 |

新しい種類の地面 (例: リングワールド) は、この窓口を実装して足す。

## 5. 宇宙の生成

すべて決まった手順で作るので、同じ場所には必ず同じものができる。保存はしない。乱数は `mulberry32` (`src/math/random.js`)。

### 5.1 銀河 (`src/universe/galaxy.js`)
- 区画は一辺 10 光年 (`:11` の `SECTOR`)。区画番号から種を作る `sectorSeed` (`:44`) は、軸ごとに順番に混ぜ込む
  (3軸の積を XOR でまとめると、符号違い・鏡像の区画が同じ種になるバグがあった。`:40-43`)。
- 1区画の恒星の数: 0 個 25%、1 個 40%、2 個 25%、3 個 10% (`:92`)。恒星どうしは 1.5 光年以上離す (`:12`)。
  区画の端から 0.75 光年には置かない (`:13`)。8回試して置けなければその星は置かない。
- 区画の結果はキャッシュし、4,000 区画を超えたら捨てる (`:115`)。

**恒星の種類** (`:17-24`)
| 種類 | 呼び名 | 出現率 | 半径 (太陽 = 1) | 明るさ |
|---|---|---|---|---|
| M | 赤色矮星 | 42% | 0.45 | 0.6 |
| K | 橙色矮星 | 25% | 0.75 | 0.8 |
| G | 黄色矮星 | 16% | 1.0 | 1.0 |
| F | 黄白色星 | 9% | 1.3 | 1.2 |
| A | 白色星 | 6% | 1.8 | 1.45 |
| B | 青白色巨星 | 2% | 3.2 | 1.8 |

半径には個体差 (×0.85〜1.15) がかかる。明るさは見た目用の値で、住みやすい帯の位置 (√明るさ に比例) とジャンプの到着距離にも使う。

**出発地** `HOME_STAR` (`:71-74`): 区画 (0,0,0) にある、銀河座標 (5,5,5) の G 型星 SOL。

### 5.2 星系 (`src/universe/system.js` の `generateSystem`, `:290-378`)
- 惑星の数は 2〜7 (`:294`)。最初の軌道半径は (0.25〜0.55) × √明るさ 天文単位で、次の惑星は 1.45〜1.95 倍の外側 (`:296`, `:325`)。
- 種類は、住みやすい帯に対する軌道の位置で決める (`:302-304`)。

| 位置 (軌道半径 ÷ √明るさ) | 種類と割合 |
|---|---|
| 0.55 未満 | 溶岩 40%、岩石 40%、砂漠 20% |
| 0.55〜1.7 | 海洋 45%、砂漠 30%、岩石 15%、氷 10% |
| 1.7 以上 | ガス巨星 45%、氷 35%、岩石 20% |

- 半径: ガス巨星 1,800〜3,400 km、ほかは 180〜620 km。実寸では 16 倍 (`REAL_SCALE`)。
- 実寸の自転周期は岩 10〜40 時間、ガス 9〜18 時間。重力は密度 (岩 3,000〜5,500、ガス 700〜1,700 kg/m³) から
  g = (4/3) π G ρ R で計算する (`gravityFromDensity`)。乱数を引く数はゲーム用と同じなので、天体の種類と並びは変わらない。
- 衛星: ガス巨星は 0〜2 個、ほかは 30% で 1 個。半径 60〜170 km、岩石か氷。互いの座標系が重ならない距離に置く。
  実寸では親の半径の 4〜40 倍の所に置き、衛星の座標系が親の地面と大気・手前の衛星の座標系に重ならないようにする (親の座標系とは重なってよい)。
- 自転周期・自転軸の傾き・重力は種類ごとの範囲から決める (`makeBody`)。

**種類ごとの大気** (`bodyLook`, `:50-121`)
| 種類 | 地表の空気の密度 (kg/m³) | 大気の高さ |
|---|---|---|
| 海洋 (terran) | 0.9〜1.5 | 60 km |
| 砂漠 (desert) | 0.15〜0.6 | 55 km |
| 氷 (ice) | 0.3〜0.9 | 50 km |
| 溶岩 (lava) | 1.2〜2.4 | 70 km |
| ガス巨星 (gas) | 4 | 220 km |
| 岩石 (rock) | なし | — |
| 都市 (city) | 1.0〜1.4 | 60 km |

小さな天体ほど起伏を低くする (半径 ÷ 400 km を掛ける、`:126-133`)。

**ほかの乱数と分けて決めるもの** (加えても、ほかの天体の配置が変わらないように)
- **都市惑星** (15%、`:19`, `:329-340`): 最初の海洋惑星か砂漠惑星を都市惑星に作り変え (`makeCity`, `:25-38`)、
  そのラグランジュ点 L4 か L5 にオニール・シリンダーを1組置く。
- **ダイソン・スウォーム** (12%、`src/universe/swarm.js:12`): 5.5節。

**小惑星帯**: 60% で1つ。惑星から十分離れた場所に置けたときだけ (`:343-351`)。

**哨戒隊** (`:353-371`)
- 危険度 = 出発地からの距離 ÷ 20 光年 (最大 3)。
- 1隊は RAIDER 2〜(2+危険度) 機 (最大 4)、25% + 危険度 × 25% で GUNSHIP を1機加える。
- 小惑星帯があれば 60% でそこに1隊。ガス巨星でなく地表の空気の密度が 0.5 以上の惑星には、35% で1隊 (都市惑星には必ず)。
  惑星の隊は、ランダムな緯度経度の高度 5 km に置く。

### 5.3 出発地 SOL (`homeSystem`, `src/universe/system.js:169-287`)
- 太陽系に似せて手で配置する。名前はラテン語。軌道半径は本物と同じ天文単位、大きさは TERRA (半径 400 km) を基準にした比率。
- 実寸 (`generateSystem(star, { scale: 'real' })`) では、半径・衛星までの距離・自転周期・重力を本物にする
  (値は `docs/design-real-scale.md` の1章)。天体ごとの `detailScale` は「実寸の半径 ÷ ゲーム用の半径」。

- 開始位置は恒星から約 1 天文単位 (`:165`)。TERRA はそこから約 3,300 km (`:167`)、小惑星帯は約 9 km (`:276`)。

- 惑星: MERCURIUS, VENUS, TERRA, MARS, IUPPITER, SATURNUS, URANUS, NEPTUNUS。主な衛星: LUNA, PHOBOS, DEIMOS, IO, EUROPA,
  GANYMEDES, CALLISTO, TITAN, TRITON。SATURNUS には環 (当たり判定なし)、IUPPITER には大赤斑がある。
- 哨戒隊: 小惑星帯に RAIDER 2機、TERRA の北緯 36°・東経 139.7° (関東平野)・高度 5 km に RAIDER 2機と GUNSHIP 1機 (`:277-280`)。

- TERRA の地形は本物の地球の標高と起伏 (`terrain.maps = { height: 'earth-height', relief: 'earth-relief' }`、倍率 1)。夜の街明かり (`nightLights: 'earth-lights'`) を持ち、
  開始時に日本 (東経 138°) が開始地点の方を向くよう `rotationPhase` を決めてある (`phaseToShow`)。

- TERRA は雲の層 (`clouds: { altitude: 4000, cover: 0.55 }`) を持つ。LUNA は潮汐ロック (`tidalLock`。自転せず、
  `axialTilt` と `rotationPhase` で表側 (緯度 0°・経度 0°) を TERRA へ向ける。`faceToward`)。
- TERRA の L5 にオニール・シリンダー `INSULA I / II` (`:272`)。

### 5.4 惑星と地形
- **惑星** (`src/planet/planet.js`): 位置・自転・地形・大気・(あれば) 環を持つ。重力は g·(R/r)² (`:170-172`)。
  空気の密度は 海面の密度 × exp(−高度 ÷ スケールハイト) で、大気の高さより上は 0 (`:176-179`)。
- **地形** (`src/terrain/terrainFn.js` の `makeTerrain`, `:72`): 単位ベクトルの方向から標高を返す関数。
  大陸・山脈・丘のノイズにドメインワープと侵食風のノイズを重ね、クレーター、段のある渓谷、崖で囲まれた台地 (メサ) を加える。
  - ノイズは単位球の上で引く。`detailScale` (省くと 1) を渡すと、尾根・丘・細かい起伏・渓谷・台地・色むら・街の周波数をその倍率だけ上げ、
    クレーターの層を足す。半径を大きくしても、これらの大きさ (m) が変わらない。大陸・山脈の分布・湿り気は球に合わせて広がる
    (実寸の惑星のため。`docs/design-real-scale.md` の3章)。天体の定義では `makeBody` (`src/universe/system.js:128`) が付ける。
  - クレーターの深さは種類ごとに既定値がある (`:15` の `CRATER_DEFAULT`。海洋惑星と都市惑星にはない)。
  - 渓谷と台地の種類ごとの設定は `CLIFFS` (`:34`)。
  - 同じ定義から、メインスレッド (接地) と Worker (メッシュ) の両方で同じ関数を作るので、見た目と当たり判定が一致する。
  - 標高 0 以下は平らな低地になり、種類によって海・乾いた盆地・氷原・溶岩の海として描く。
  - `terrain.maps` (`{ height?, cover?, albedo?, relief? }`) があると、本物の地形のマップ (`src/terrain/maps.js`) を使う。
    大きな模様をマップの標高 (× `heightScale`) に置き換え、マップの画素の 2 倍より短い波長のノイズだけを足す。
    海岸 (標高 0〜60 m) では細かい模様を弱め、海底には足さない。渓谷・台地は作らず、マップより大きなクレーターも足さない。
    `cover` は土地被覆の区分 (IGBP) で海洋惑星の色と木を、`albedo` は岩石天体の明るさを決める。
    `relief` (画素の中の最高点が平均よりどれだけ高いか、m) があると、海洋惑星の尾根のノイズの強さをこの値で決める。
    尾根のノイズは平均を引いてマップの高さを変えず、上位 3% が「平均 + 起伏」に届くよう、地形を作るときに決まった 512 点で目盛りを合わせる
    (足し始めるオクターブが縮尺で変わり、値の散らばり方が違うため)。起伏より上に出た尾根は 3 割に縮める。
    マップは使う前に読み込んでおく (`main.js` が開始前に SOL の分を読む。Worker は自分で読む)。読み込めなかったマップを使う天体は、
    `usableTerrain` で今のノイズの地形にする (`docs/design-earth-moon.md` の 3章・7章)。
  - 天体の定義の `nightLights` (マップの名前) があると、地表のシェーダーがそのマップをテクスチャにして、夜側に街明かりを足す
    (`src/planet/atmosphere.js` の `LIGHTS_GLSL`。近づくと細かい点に分ける)。地形の Worker は読まない。読み込めなければ街明かりなしで描く。
- **LOD** (`src/planet/planetLod.js`): 立方体の6面を球に投影した「キューブ球」の各面を四分木にし、カメラに近い所ほど細かくする。
  - チャンクの大きさの 1.3 倍まで近づいたら細分化し、統合には 1.15 倍の余裕を持たせる (`:4-5`)。最も細かいレベルの頂点間隔は約 1.2 m (`:6`)。
  - チャンクは 32×32 分割 (`src/terrain/chunkBuilder.js:4`)。境目の隙間はスカートで隠す。
  - メッシュは Worker で作る。Worker の数は (CPU のスレッド数 − 2) を 2〜6 に収めたもので、全惑星で1組を共有し、近いチャンクから作る
    (`src/planet/planetLod.js:16`, `:66-69`)。Worker は惑星ごとに地形関数を使い回す (`src/terrain/terrainWorker.js`)。
    使い回す名前には天体の名前・半径・`detailScale` を入れる (`src/planet/planetLod.js` の `workerDef`)。惑星の大きさの設定を変えても古い地形を使わない。
  - ガス巨星も同じ LOD で描く。標高はどこでも 0 で、色は緯度ごとの縞 (`src/terrain/gasBands.js`)。最も細かいレベルの頂点間隔は 200 m
    (雲の頂きの 40 km 上より下へは行けないため)。以前の 128×64 の球は、実寸の木星で面の平らな所が 21 km へこむのでやめた。
- **岩・木・ビル** (`src/planet/scatter.js`): 区画ごとに同じ乱数で決める。岩と木には当たり判定がない。
  木は 350 m より遠くをビルボードで描き、3 km より先は描かない (`:14-15`)。ビルは 4.5 km 先まで描き、その先は地表のシェーダーの模様が引き継ぐ (`:18`)。
- **都市惑星の街区** (`src/planet/city.js`): 約 200 m の区画を 4×4 の敷地に分け、敷地ごとのビルを決める (`:11-12`)。
  描画と屋上の当たり判定 (`src/planet/planet.js:161-167`) の両方がこの計画を使う。
- **大気** (`src/planet/atmosphere.js`): 大気の殻と地表を、レイリー散乱とミー散乱のシェーダーで描く。都市惑星の道路と夜景もここ。
  - 雲 (`CLOUD_GLSL`、`def.clouds` のある天体だけ #define `CLOUDS`): 半径 `uCloudR` の薄い球面として、視線・太陽光との交点で濃さを求める
    (メッシュは使わない)。濃さは回る 2 枚のノイズと緯度ごとの量で決め、1 ピクセルより細かい模様は消す。空と地表に重ね、地表には影を落とす。
    実寸ではオクターブを足して、いちばん小さな雲の大きさ (m) を保つ。
  - 道路の格子の座標は、カメラのいる面での値を CPU で倍精度のまま計算して渡し (`setCamLot`, `src/planet/planet.js`)、
    シェーダーはカメラからの差だけを計算する。実寸の惑星では敷地の座標が 20 万を超え、float のままだと 0.4 m ずれて道路がちらつくため。

### 5.5 ダイソン・スウォーム (`src/universe/swarm.js`)
- 12% の星系 (出発地にはない) にある。被覆率は 0.3〜0.75 (`:28-33`)。
- いちばん内側の惑星より内側の半径に、傾きの違う 3〜9 本の帯を作り、六角形のパネルを並べる。パネルの総面積 ≒ 被覆率 × 球の面積 (`:41-60`)。
- パネルの半径は帯の半径の 1.6% (`:14`)、厚さはパネルの半径の 0.4% (`:20`)。当たり判定はパネルの内接円より少し小さい円 (`:22`)。

### 5.6 オニール・シリンダーの外 (`src/universe/habitat.js`)
- 半径 4 km、長さ 32 km、外壁の厚さ 60 m。2本の軸の間隔は直径の 2.5 倍 (`:10-20` の `HABITAT`)。

### 5.7 オニール・シリンダーの中
- 円筒ローカル座標は回らない。重力は軸から外向きに g·r/R (地面で 1 g、軸で 0) (`src/universe/habitat.js:124-126`)。
- 空気の密度は 1.2 × exp(g (r² − R²) ÷ (2R · 287 · 288)) (地面で 1.2 kg/m³、軸で約 0.79 倍) (`src/universe/habitat.js:129-132`)。
- 内壁を周方向に6等分し、陸の帯 (θ = 0°, 120°, 240° を中心に幅 60°) と窓の帯 (平らなガラス) を交互に並べる
  (`src/universe/habitatTerrain.js:8`, `:20-21`)。
- 陸の帯には丘・湖・川・町 (区画 1.5 km)・森。両端の蓋の前は 1,100 m の段々畑の山 (1段 110 m) (`src/universe/habitatTerrain.js:22-24`)。
- 宇宙港: 入港口の側の端から 4.2 km、半径 320 m の平らなパッド (高さ 8 m)。パッドとそのまわりには木も家も置かない (`src/universe/habitatTerrain.js:29`)。

- 描画: 中の地形は Worker を使わず、本体で1フレーム 5 ms までずつ作る。帯の幅方向に 4、軸方向に 1 km ごとのチャンク。
  木と家は 2.5 km 以内を 200 m の区画ごとに決める (`src/render/habitatInterior.js:16-22`)。
- 安全地帯: 敵は片付けられ、増援は呼べず、巡航は使えない。

## 6. 飛行モデル

### 6.1 剛体 (`src/physics/body.js`)
- 6自由度の剛体。位置・速度は世界座標 (フレーム座標)、角速度・トルクは機体座標。機体座標は 前 = −Z、上 = +Y、右 = +X (`:10-15`)。
- 積分は半陰的オイラー法。ジャイロ項 (ω × Iω) は、操縦系が常に角速度を制御するので省いている (`:57-66`)。
- 描画用に1ステップ前の状態を持ち、補間する。

### 6.2 機体 (`src/flight/ship.js` の `Ship.applyForces`, `:144-287`)
1 ステップの中の順番。
1. 巡航をやめる途中なら、速さを v0 から 400 m/s まで、2.5 秒かけて毎秒同じ比率で落とす (`:150-167`)。
2. 着陸装置を 1.6 秒かけて出し入れする。
3. 重力をかける (巡航中はかけない)。
4. 空気力をかける (6.3節。巡航中は空気がないものとして扱う)。
5. 空力加熱: 目標値 = √(密度 ÷ 1.225) × 速さ³ ÷ 3e9 に、時定数 2.5 秒で近づく。1 を超えた分 × 12 /秒 で機体が傷む
   (`:187-191`, `src/flight/shipParams.js:65`)。
6. 回転 (`:200-213`)
   - アシスト ON: 入力 × 最大角速度 を目標に、角速度の誤差 × 9 の角加速度で合わせる。空気が機首を振る力も打ち消す。
     最大角加速度で上限を切るので、高速では引ける迎角 (= G) に上限が生まれる。
   - アシスト OFF: 入力 × 最大角加速度 のトルクをそのままかける。
7. 並進 (`:215-287`)。モードによって決め方が変わる (6.5節)。
8. 噴射量 `thrustLevel` (見た目と音に使う) と、ブースト中かどうか `boosting` を求める (`:283-284`)。

### 6.3 空力 (`src/flight/aero.js` の `computeAero`)
- 揚力係数: 迎角 α について、線形の CL = cl0 + clα·α と、失速後の平板の揚力 0.9·sin 2α を、
  失速角 (約 18°) から幅 0.14 rad で滑らかに切り替える (`:69-72`)。
- 抗力係数: 失速前は cd0 + k·CL²、失速後は平板の抗力。これに着陸装置の抗力と造波抵抗を足す (`:73-76`)。
  造波抵抗はマッハ 0.85 から増え、1.15 で最大 (`waveDragCoef`, `:27`)。
- 揚力は速度に垂直で機体の対称面内、抗力は速度と逆向き、横力は横滑りを打ち消す向き (`:79-90`)。
- トルク: 機首を進行方向へ戻す風見安定と、回転の減衰。この組み合わせで高速旋回は約 13 G (`src/flight/shipParams.js:58-60`)。
- 失速の判定: 切り替えが半分を超え、動圧が 150 Pa を超えるとき (`:77`)。

### 6.4 モードの決まり方
HUD の `MODE` は、次の順に調べて最初に当てはまったもの (`src/game.js:1232-1236`)。

| MODE | 条件 |
|---|---|
| CRUISE / CRUISE END | 巡航中 / 巡航をやめる途中 |
| MANUAL | アシスト OFF |
| HOVER | ホバー (`H`) が ON で、`env.aero` > 0.05 |
| AERO | `env.aero` > 0.5 |
| SPACE | それ以外 |

`env.aero` は「航空機として飛べる度合い」(0〜1)。海面に対する空気の密度の比が 0.01〜0.08 の間で 0→1 に滑らかに変わる
(高度 約 32〜18 km、`src/game.js:343-345`)。

**`MODE` は表示のための名前で、コードにモードごとの分岐があるわけではない。** 実際の操縦は、次の3つの値で連続的に決まる。

| 値 | 意味 | 決め方 |
|---|---|---|
| `h` (`hoverAuthority`) | 「ホバー・宇宙の操縦則」の重み。1 − h が「航空機の操縦則」の重み | ホバー ON なら 1、そうでなければ 1 − `env.aero` (`src/flight/ship.js:228-229`) |
| `vtol` | 低速の目標速度 (VTOL の値) を使う度合い | max(ホバー ON なら `env.aero`、そうでなければ 0, 脚の出具合) (`src/flight/ship.js:231`) |
| `scale` | 巡航の倍率 (巡航中でなければ 1) | 6.7節 |

このため、大気の境目 (高度 約 32〜18 km) では2つの操縦則が少しずつ入れ替わり、脚を出し入れしている途中は目標速度も少しずつ変わる。

### 6.5 モードごとの操縦の仕組み
アシスト ON の並進は、2つの操縦則で求めた加速度を `h` で混ぜたもの (`src/flight/ship.js:271-273`)。
回転はどのモードでも同じ (6.2節の 6.)。

**操縦則 A: 航空機** (`src/flight/ship.js:222-225`)
- 前後: スロットル ≥ 0 なら スロットル × 主エンジンの加速 (45 m/s²、ブーストで 2.6 倍、巡航中はさらに × `scale`)。
  スロットル < 0 なら スロットル × 逆噴射の加速 (30 m/s²)。
- 上下左右: 入力 × 22 m/s² をそのままかける。
- 重力は打ち消さない。機体を支えるのは翼の揚力 (6.3節)。

**操縦則 B: ホバー・宇宙** (`src/flight/ship.js:232-270`)
- スロットルを「目標速度」として扱う。
  - 前: スロットル × 上限 × `scale`。上限は 400 m/s と VTOL の 80 m/s を `vtol` で混ぜたもの (ブースト中は 1,100 と 200)。
  - 後ろ: スロットル × 120 m/s と VTOL の 30 m/s を `vtol` で混ぜたもの (ブーストの値はない)。
  - 上下左右: 入力 × 80 m/s と VTOL の 30 m/s を `vtol` で混ぜたもの。
- 加速度 = (目標速度 − 今の速度) × 3 (`assistLinearGain`) − 重力。**重力も打ち消す**ので、手を離すと空中で止まる。
- 加速度には上限がある。
  - 上下左右: 150 m/s² × `strong` (`assistLateralAccel`)。
  - 前: 主エンジンの加速まで。後ろ (減速): 30 m/s² × `strong`。
  - `strong` = max(`scale`, 速さ ÷ 400 m/s) (`src/flight/ship.js:246`)。巡航を切った直後など、通常より速いときは強く止める。
- 接地していて何も指示していなければ (`idle`)、エンジンを絞って脚に重さを預ける (`src/flight/ship.js:239-241`)。
- 着陸の補助: 脚が半分以上出ていて降下しているとき、降下の目標速度を max(3, 高度 × 0.15) m/s までに抑える (`src/flight/ship.js:252-257`)。

**各モードでの組み合わせ**
| MODE | `h` | `vtol` | 振る舞い |
|---|---|---|---|
| SPACE | 1 (宇宙)。薄い大気では 1 − `env.aero` | 脚の出具合 | 操縦則 B。手を離すと止まる。脚を出すと目標速度が 80 m/s に下がる |
| AERO | 1 − `env.aero` (濃い大気で 0) | 脚の出具合 | 操縦則 A。翼の揚力で飛び、速さは推力と抗力の釣り合いで決まる。遅いと失速する |
| HOVER | 1 | `env.aero` と脚の大きい方 | 操縦則 B を低速で。大気中でも空中で止まる。`R` / `F` で上昇・下降 |
| CRUISE | 1 (空気を無視するので `env.aero` = 0 として扱う) | 0 (巡航に入ると脚をしまう) | 操縦則 B の目標速度と主エンジンを `scale` 倍。重力と空気力をかけない。減速と横滑りの打ち消しを「速さ ÷ 0.5 秒」まで強める (6.7節) |
| CRUISE END | 同上 | 同上 | 速さを 2.5 秒かけて 400 m/s まで落とす。`scale` は max(1, min(`scale`, 今の上限 ÷ 400)) (`src/flight/ship.js:150-167`) |
| MANUAL | 0 | — | 入力をそのまま加速度・角加速度にする (`src/flight/ship.js:275-281`)。重力と空気力はそのまま受け、止めるには逆向きに噴射する |

補足
- ホバー (`H`) は宇宙でも ON にできるが、宇宙では `env.aero` = 0 なので `h` も `vtol` も変わらず、振る舞いは SPACE と同じ。
- 巡航は「巡航 ON かつアシスト ON」のときだけ働く (`driving`, `src/flight/ship.js:76-78`)。巡航に入るとアシストは ON になり、
  巡航中に `Z` を押すと、減速し終わってからアシストが切れる (`src/game.js:170-175`)。
- 巡航をやめたとき、速さがすでに 400 m/s 以下なら減速の段階を飛ばしてすぐ終わる (`src/flight/ship.js:92-97`)。

### 6.6 ブースト
- 入力: `Shift` (左右どちらでも) かゲームパッドの A を押している間 (`src/core/input.js:164`, `:177`)。0 か 1 で、中間はない。
- 効果 (`src/flight/ship.js:216-217`, `:232-234`)
  - 主エンジンの加速を 2.6 倍 (`boostMultiplier`, `src/flight/shipParams.js:15`) にする。45 m/s² → 117 m/s²。
  - 操縦則 B の前向きの目標速度の上限を、400 → 1,100 m/s (`assistBoostSpeed`)、VTOL では 80 → 200 m/s (`vtolBoostSpeed`) にする
    (`src/flight/shipParams.js:19`, `:36`)。
  - 逆噴射・上下左右のスラスター・後ろ向きの目標速度は変わらない。
- モードごとの結果

| MODE | 通常 | ブースト中 |
|---|---|---|
| SPACE | スロットル 100% で 400 m/s | 1,100 m/s |
| HOVER・脚を出しているとき | 80 m/s | 200 m/s |
| AERO | 海面の最高速度 約 400 m/s | 約 730 m/s (造波抵抗との釣り合い、`src/flight/shipParams.js:49`) |
| CRUISE | 倍率 × 400 m/s | 倍率 × 1,100 m/s。距離が 1/e になる時間が 1/2.75 になる |
| MANUAL | 加速 45 m/s² | 加速 117 m/s²。速さの上限はない |

- 目標速度は スロットル × 上限 なので、スロットル 0 ではブーストしても何も起きない。
- 消費するものはない (燃料・エネルギー・熱の消費なし)。ただし大気中で速く飛べば、空力加熱は速さの3乗で増える。
- 「ブースト中」(`boosting`) は、ボタンを押していて、噴射量 `thrustLevel` が 5% を超えているときだけ true (`src/flight/ship.js:283-284`)。
  アシスト ON で目標速度に届くと噴射量が下がるので、押したままでも false になる。`boosting` が true の間の演出は次のとおり。
  - HUD: `BOOST` の表示、スロットルの棒の色 (`src/ui/hud.js:206`, `:239-241`)
  - 噴射炎: 青 → 橙 (`src/render/shipModel.js:167`)
  - 画角: 最大 +14°。時定数 0.25 秒で滑らかに変わる (`src/game.js:888`, `src/camera/cameraRig.js:96`)
  - エンジン音: 音量と高さが上がる (`src/audio/sound.js:90-91`)
- 敵も同じ規則でブーストする。AI は、遠く (8 km 超) の的を正面に捉えて追うときなどに使う (`src/combat/ai.js:169`)。
  GUNSHIP はブーストしても 700 m/s まで (`src/flight/shipParams.js:112`)。

### 6.7 巡航 (`src/flight/cruise.js`)
- 最高速 = 倍率 × 400 m/s。倍率 = max(5, min(d, 1e6) ÷ 1200 + max(0, d − 1e6) ÷ 700) (`src/flight/cruise.js:10-21`)。
  天体に向かって全開で飛ぶと、残りの距離は天体の近くで約 3 秒ごと、1,000 km より遠くで約 1.75 秒ごとに 1/e になる。
  所要時間 (地表から 15 km の所から、到着先の 15 km 手前まで): 惑星間 0.5 天文単位で約 1 分、恒星間 5 光年で約 1分50秒。
  ブーストでは目標速度が 1,100 m/s になるので、それぞれ約 23 秒、約 40 秒 (`tests/m5.test.js` の `travelTime`)。
  d はいちばん近い天体の表面 (惑星の地表、恒星の表面、シリンダーの外壁) までの距離 (`game.cruiseDist`, `src/game.js:366-417`)。
  スウォームのパネルまでの距離は入れない。
- 巡航中は、減速と横滑りの打ち消しを「速さ ÷ 0.5 秒」の強さで行う (`src/flight/shipParams.js:31`)。
  こうしないと、天体に近づいて上限が急に下がったときに付いていけず、目的の天体を回り込んでしまう (`src/flight/ship.js:248-250`)。
- 入ると、アシストを ON にし、着陸装置をしまう (`src/game.js:182-185`)。

### 6.8 接地 (`src/flight/ground.js` の `GroundContact`)
- 接触点は 脚3本 (主脚2本と前脚1本) と、機体の外形の点。点ごとに、窓口の `upAt` と `heightAbove` で真下の地面を調べる。
  真下の地面の点は「点 − 真上 × 高さ」で求める。
- 脚はばねとダンパー (1本 157,000 N/m、静止時に約 0.25 m 沈む)、転がり・ブレーキ・横の摩擦を持つ (`:23-31`)。
  ブレーキはホバー中かスロットルが 1% 以下のときにかかる (`src/game.js:299`)。
- 損傷: 脚は 7 m/s、機体は 2.5 m/s を超える接地で傷む。機体を擦りながら滑ると 1 m あたり 0.15 傷む (`:30`, `:37-39`)。
- 崖: 1ステップで地面から 2 m より深く入った点は、壁を抜けたものとして、前のステップからの経路が地面を横切る所を探して押し戻す (`:49`, `:247-249`)。
- 静止摩擦: ほぼ止まっていて、3本の脚だけが接地し、地面が約 35° より緩ければ、滑った分を戻す (`src/game.js:311-320`)。

## 7. 戦闘

### 7.1 機体の性能 (`src/flight/shipParams.js`)
| 項目 | 自機 (FIGHTER) | RAIDER | GUNSHIP |
|---|---|---|---|
| 機体 / シールド | 100 / 100 | 60 / 50 | 170 / 120 |
| 当たり判定の半径 | 7 m | 7 m | 10 m |
| 主エンジン | 45 m/s² | 45 m/s² | 30 m/s² |
| 最高速 (アシスト / ブースト) | 400 / 1,100 m/s | 400 / 1,100 m/s | 320 / 700 m/s |
| 機関砲 (毎秒の発射数 / 1発の損傷) | 10 / 6 | 6 / 4 | 5 / 7 |
| ミサイル (数 / 損傷 / 間隔) | 6 / 70 / 1 秒 | なし | 4 / 55 / 10 秒 |
| 出典 | `:7-92` | `:97-102` | `:105-116` |

敵は自機と同じ `Ship` を、人間と同じ操縦入力で飛ばす。

### 7.2 損傷とシールド
- 攻撃はまずシールドが受け止め、あふれた分が機体に入る (`src/flight/ship.js:111-117`)。
- シールドは最後の被弾から 4 秒後、毎秒 12 回復する。機関砲のエネルギーは常に毎秒 14 回復する (`src/flight/ship.js:120-125`)。

### 7.3 弾 (`src/combat/projectiles.js`, `src/combat/targeting.js`)
- 機関砲の弾は実体として飛ぶ。弾速 1,800 m/s に射手の速度を上乗せし、1.4 秒で消える。
- 当たりは「1ステップで動いた線分」と「的の球」の交差で調べるので、速くてもすり抜けない (`segmentSphere`, `targeting.js:45`)。
  味方には当たらない。地形と小惑星との判定は 6 ステップに1回。
- 見越し点: |相対位置 + 相対速度·t| = 弾速·t を満たす最小の t > 0 (`leadPoint`, `targeting.js:14`)。当てられないときは表示しない。
- 見越し点が機首から 2° 以内なら、砲がそちらへ向く (`src/flight/shipParams.js:84` の `gunGimbal`)。

### 7.4 ミサイル (`src/combat/projectiles.js:127-135` の `MISSILE`)
| 項目 | 値 |
|---|---|
| 加速 / 燃焼時間 / 最高速 | 170 m/s² / 6 秒 / 1,300 m/s |
| 曲がる力 | 200 m/s² (約 20 G) |
| 寿命 | 11 秒 |
| 的を見失わない角度 | 約 60° |
| 起爆の距離 | 的の半径 + 6 m |

自機のロックオン: 的を機首から 25° 以内・5 km 以内に 1.5 秒捉え続ける (`src/flight/shipParams.js:88-90`)。

### 7.5 的の選び方 (`src/combat/combat.js:456-488`)
- `T`: 「機首からの角度 + 距離 ÷ 40 km」がいちばん小さい敵。
- `Y`: 距離の順で、今の的の次の敵。
- 的がいなければ、0.5 秒 (60 ステップ) ごとに 10 km 以内のいちばん近い敵を自動で選ぶ (`:14`, `:496-507`)。

### 7.6 敵の振る舞い
**AI** (`src/combat/ai.js`): 状態は 哨戒 (patrol) → 攻撃 (attack) ⇄ 回避 (evade) / 離脱 (break)。
- 哨戒中は、5 km 以内に自機が来るか、警戒状態になると攻撃に移る (`:32`, `:98-99`)。
- 攻撃中、ミサイルに狙われたか、撃たれた・後ろに付かれたときに確率で回避に移る (機体が 40% 未満だと移りやすい) (`:103-114`)。
- 300 m 以内で近づき続けているときは、すれ違って距離を取り直す (`:115-120`)。
- 腕前 (0〜1) が狙いの正確さと撃ち始める角度を決める。小惑星と地面を避ける。

**哨戒隊と出現** (`src/combat/combat.js`)
- 哨戒隊の中心から、小惑星帯なら 30 km、惑星なら 40 km 以内に入ると、その隊が現れる (`:143`, `:149`, `:306-330`)。
- 誰かが撃たれると、その敵と 6 km 以内の仲間が警戒状態になる (`:444`)。
- 自機から 60 km 離れた敵は消える。哨戒隊の生き残りは、次に近づいたときにまた現れる (`:13`, `:311-313`)。
- 一度にいる敵は最大 8 機 (`:10`)。出せなかった分は次に回す。
- 設定「敵の出現」が OFF なら、いる敵も消し、出さない (`:309-314`)。

**増援** (`reinforce`, `:339-381`): 呼ぶたびに数が増え、RAIDER min(1 + 回数, 4) 機と、3回に1回 GUNSHIP 1機。
自機の前方 5〜7 km に出し、地面から 1,500 m 以上の高さを確保する。初めから警戒状態。シリンダーの中と設定 OFF では呼べない。

### 7.7 修理と補給 (`src/combat/combat.js:717-738`)
`LANDED` (3本の脚が接地し、毎秒 1 m 未満、`src/game.js:369`) が 3 秒続き、機体かミサイルが減っていれば、機体を毎秒 25 回復する。
機体が満タンになるとミサイルも満タンにする。

### 7.8 そのほかの損傷 (`src/game.js:521-598`)
| 原因 | 条件 | 損傷 |
|---|---|---|
| 恒星 | 恒星の中心から半径の 1.6 倍以内 | 毎秒 30 × (1 + 近さに応じた倍率) |
| スウォームのパネル | 面に向かう速さ 15 m/s 超 | min(120, 速さ × 0.6)。跳ね返り、巡航が止まる |
| シリンダーの蓋 (中) | 同上 | 同上 |
| シリンダーの外の部品 | 同上 | 同上 |
| ガス巨星 | 海面の高さから 40 km 未満 | 毎秒 25 |

### 7.9 復帰 (`src/game.js:795-816`)
機体を失ってから 3.5 秒後、機体・シールド・エネルギー・ミサイル・熱を元に戻して復帰する (`Ship.restore`, `src/flight/ship.js:128-135`)。
| 失った場所 | 復帰の場所 |
|---|---|
| 惑星の座標系 | その場所の 300 m 上空、ホバーで静止 (`placeShip`, `src/game.js:825-853`) |
| ガス巨星 | 大気の上端から 60 km 上 |
| シリンダーの中 | 宇宙港の上空 |
| 宇宙 | その場所。恒星の半径の 6 倍より近ければ、そこまで離す |

### 8.1 行き先 (`game.nav`)
| type | 行き先 | 距離の測り方 |
|---|---|---|

  max(半径 × 20, 200 km) 以内なら、距離を 1.2 倍ずつ (最大 8 回) 伸ばす (`:714-722`)。
- 到着時は止まって恒星の方を向き、巡航は切れ、スロットルは 0。敵と弾は片付ける。

## 10. 音 (`src/audio/sound.js`)

- すべて Web Audio で合成する (音声ファイルはない)。最初の操作で `AudioContext` を作る。使えない環境では無音で続ける (`:17-23`)。
- 鳴り続ける音: エンジン (推力で音量と高さが変わる)、低いうなり、姿勢制御スラスター、風 (動圧で強く、速さで高く) (`update`, `:84`)。
- 単発の音: 接地 (`thump`)、着陸装置、爆発、機関砲、被弾、シールド被弾、ミサイル、クリック。
- 一時停止中は無音。音量は設定の「音量」。

## 11. 設定と保存 (`src/core/settings.js`)

- 設定項目は `SETTING_DEFS` (`:4-25`) に定義し、メニューはこの一覧から自動で作る。項目を足すには1行足すだけでよい。

  読み込むときは、既定値と型が同じ値だけを使う。選択式 (`type: 'select'`) は、今ある選択肢の値だけを使う (`:34-35`)。保存領域が使えない環境では既定値のまま動く。

- 設定のほかに保存するものはない。宇宙・機体の状態・撃墜数は再読み込みで最初に戻る。
