# STARWAKE 操作マニュアル

ブラウザで動く宇宙フライトシミュレーター STARWAKE の遊び方をまとめた文書。
仕組みや規則の詳しい説明は仕様書 (`docs/spec.md`)、アルゴリズムの解説は技術解説 (`docs/index.html`) を見る。

本文の数値は書いた時点のもので、正しいのはコードの方。どの数値がどのファイルの何行目から来ているかは、
最後の「付録: 数値の出典」にまとめてある。

---

## 1. はじめに

### 動作環境
- WebGL が動く PC のブラウザ。マウスとキーボードで遊ぶ。ゲームパッド (標準配置) も使える。
- Three.js をインターネット (CDN) から読み込むので、ネットに接続しておく。

### 起動
1. プロジェクトのフォルダで、開発用のサーバーを立てる。Python があれば `python serve.py`、
   Node.js があれば `npx --yes http-server@14.1.1 . -p 5173 -a 127.0.0.1 -c-1 -s` (README の「起動」)。
2. ブラウザで http://localhost:5173/ を開く。
3. 「操作方法と設定」の画面が出るので、**クリックして開始** を押す。
4. 画面をクリックするとマウスが画面に固定され、マウスで操縦できるようになる。

### 最初の状況
出発地は太陽系に似せた **SOL 星系**。恒星から約 1 天文単位の宇宙空間に、止まった状態で始まる。
すぐ近く (中心まで約 3,300 km) に惑星 **TERRA** があり、すぐそばには小惑星帯がある。
小惑星帯と TERRA の上空には敵の哨戒隊がいる (近づかなければ襲ってこない。7章)。

## 2. 画面の見方

### 2.1 中央
| 表示 | 意味 |
|---|---|
| 十字 | 機首の向き。機関砲はここへ撃つ |
| 十字のまわりの薄い円と点 | マウスの仮想スティックの倒れ具合 (3章) |
| 速度ベクトルの印 | 機体が実際に進んでいる向き (前進側と後退側の2つ) |
| 姿勢の目盛り | 惑星の近くでだけ出る水平線とピッチの目盛り (10° ごと) |

### 2.2 左側: 速度とエンジン
| 表示 | 意味 |
|---|---|
| `SPD` / `AIRSPEED` | 速さ。大気の中では `AIRSPEED` になる。速さに応じて m/s → km/s → c (光速) → ly/s と単位が変わる |
| `V/S` | 上昇率 (惑星の近くだけ) |
| `G` | 操縦席で感じる G (惑星の近くだけ) |
| `AoA` | 迎角 (大気の中だけ) |
| 縦の棒と `THR` | スロットル (-100%〜100%)。ブースト中は色が変わる |
| `SHLD` | シールドの残り |
| `GUN` | 機関砲のエネルギー。撃つと減り、撃たなければ回復する |
| `MSL` | ミサイルの残り |

### 2.3 右側: 機体の状態
| 表示 | 意味 |
|---|---|
| `FA ON/OFF` | フライトアシスト (4章)。OFF のときは警告色 |
| `VIEW` | 視点 (`COCKPIT` / `CHASE`) |
| `MODE` | 操縦のモード。`SPACE` / `AERO` / `HOVER` / `CRUISE` / `CRUISE END` (巡航をやめて減速中) / `MANUAL` (アシスト OFF) |
| `GEAR ...` / `GEAR DOWN` | 着陸装置が動いている途中 / 出ている |
| `HULL` | 機体の耐久。70% 未満で黄色、35% 未満で赤 |
| `HEAT` | 空力加熱。10% を超えると表示される。100% を超えると機体が傷む |
| `BOOST` | ブースト中 |
| `GROUND` / `LANDED` | 接地している / 3本の脚で接地して止まっている |

### 2.4 上・下・左下
| 場所 | 表示 | 意味 |
|---|---|---|
| 上 | 方位 (例 `045° NE`) | 惑星の近く (海面から 150 km 以内) でだけ出る |
| 上 | `NAV 名前 距離 ETA 時間` | 行き先・距離・今の速さで着くまでの時間。別の恒星なら `K でジャンプ` も出る |
| 下 | `ALT` と、天体名・`SEA LEVEL` | 惑星の座標系に入っているとき。地面からの高さと海面からの高さ |
| 下 | `軸まで ... m 重力 ... G` | オニール・シリンダーの中にいるとき (`SEA LEVEL` の代わり) |
| 下 | `星系名 恒星まで 距離` | 宇宙にいるとき |
| 左下 | レーダー | 上が機首の方向。円の半径は 6 km。縦の線は上下のずれ |
| 左下 | `HOSTILES` / `KILLS` | 今いる敵の数 / 撃墜した数 |
| 左上 | fps・chunks | 動作の重さの目安 (表示している地形の区画の数、読み込み待ちの数) |

### 2.5 目印
- **ひし形と名前・距離**: 惑星・衛星。遠くて小さく見えるときだけ出る。オニール・シリンダーは2本1組で1つの目印になる。
- **行き先の目印**: 選んだ行き先。画面の外にあるときは、その方向を示す。
- **赤い三角と `HOSTILES`**: 敵の哨戒隊がいる場所。
- **敵機の枠と矢印**: 敵機。画面の外にいるときは矢印で方向を示す。的にしている敵には名前・距離・接近の速さが出る。
- **緑の丸**: 見越し点。ここに十字を重ねて撃つと当たる (7章)。

### 2.6 警告と知らせ
画面の中央やや上に出る。

| 表示 | 意味 |
|---|---|
| `STALL` | 失速している。機首を下げて速度を回復する |
| `OVERHEAT` | 加熱が限界を超えた。速度を落とすか高度を上げる |
| `GEAR` | 地面の近く (150 m 未満) を毎秒 8 m 以上で降下しているのに、脚が出ていない |
| `MISSILE` (点滅) | 敵のミサイルに狙われている |
| `機体喪失 — 上空で復帰します` | 機体を失った (8章) |
| `修理・補給の準備中…` / `修理・補給中…` | 着陸して止まっている (8章) |
| 黄色の短い文 | 星系に入った、入港した、ジャンプできない理由など |

### 3.2 マウスの仮想スティック
マウスは「倒したままになるスティック」として働く。マウスを動かした分だけスティックが倒れ、戻すまで倒れたまま。
感度 ×1 では 260 px 動かすと最大まで倒れる。中央付近のわずかな倒れ (6%) は無視される。
まっすぐ飛びたいときは `C` か中クリックで中央に戻す。

ブラウザがマウスの固定を許さない環境では、画面の中央からマウスまでの位置がそのままスティックの倒れになる。

### 3.3 ゲームパッド (標準配置)

| 左スティック | ロール / ピッチ |
| 右スティック | ヨー / 上下のスラスター |
| RT / LT | スロットルを上げる / 下げる |
| A | ブースト |
| B | 着陸装置 |
| X | フライトアシスト |
| Y | 視点 |
| LB | ホバー |

| 右スティック押し込み | ミサイル |

巡航・星図・行き先・ジャンプ・増援はゲームパッドに割り当てがないので、キーボードを使う。

## 4. 飛び方

### 4.1 フライトアシスト
`Z` で切り替える。

- **ON (ふつうはこちら)**: スロットルや手の操作を「目標」として、機体が自動で噴射を調整する。
  手を離すと回転が止まり、横滑りも打ち消される。
- **OFF (`MODE MANUAL`)**: 噴射した分だけ加速し続ける、慣性そのままの飛び方。止まるには逆向きに噴射する。

### 4.2 4つのモード
フライトアシストが ON のとき、操縦の仕方は場所によって自動で変わる。今のモードは HUD の `MODE` に出る。

| MODE | 場所 | スロットルの意味 | 手を離すと |
|---|---|---|---|
| SPACE | 宇宙、または薄い大気 (高度 約 32 km より上) | 目標の速さ。100% で 400 m/s、ブーストで 1,100 m/s、逆噴射側は最大 120 m/s | 止まる (重力も打ち消す) |
| AERO | 大気の中 | エンジンの推力 | 翼の揚力で飛び続ける。約 70 m/s を下回ると失速する |
| HOVER | 大気の中で `H` | 目標の速さ (低速)。100% で 80 m/s、ブーストで 200 m/s | 空中で止まる。`R` / `F` で上昇・下降 |
| CRUISE | `J` | 目標の速さ × 天体からの距離で決まる倍率 (5章) | 重力も空気も無視して飛ぶ |

- 高度 約 32 km から 18 km にかけて、SPACE の飛び方から AERO の飛び方へ少しずつ切り替わる。
- AERO では海面近くの最高速度が約 400 m/s、ブーストで約 730 m/s。音速 (340 m/s) の手前から空気の抵抗が急に増える。
- 迎角が約 18° を超えると失速が始まる (`STALL`)。
- 大気の中を速く飛ぶと機体が熱くなる (`HEAT`)。空気が濃いほど、速いほど熱くなる。100% を超えると機体が傷む。巡航中は熱くならない。
- 着陸装置を出していると、宇宙でも目標の速さが HOVER と同じ低速 (100% で 80 m/s) になる。大気のない天体に降りるときに細かく動かせるようにするため。

### 4.3 ブースト
`Shift` (ゲームパッドは A) を押している間、主エンジンの推力が 2.6 倍になり、目標の速さの上限も上がる。
燃料などの消費はなく、押し続けられる。

| MODE | 通常 | ブースト中 |
|---|---|---|
| SPACE | 100% で 400 m/s | 100% で 1,100 m/s |
| HOVER (と、脚を出しているとき) | 100% で 80 m/s | 100% で 200 m/s |
| AERO | 海面近くの最高速度 約 400 m/s | 約 730 m/s |
| CRUISE | 倍率 × 400 m/s | 倍率 × 1,100 m/s (同じ距離を約 2.75 倍の速さで飛ぶ) |
| MANUAL | 加速 45 m/s² | 加速 117 m/s² (速さの上限はない) |

- スロットルは効いたまま。スロットル 50% でブーストすると、SPACE では 550 m/s になる。スロットル 0 では何も起きない。
- 強くなるのは前進だけ。逆噴射と、上下左右のスラスターは変わらない。後退の速さも変わらない。
- ブースト中は、HUD に `BOOST` が出て、スロットルの棒の色が変わる。噴射炎が青から橙になり、画角が少し広がり、エンジン音が高くなる。
  これらは加速している間だけ出る。目標の速さに届くと、押したままでも消える。
- 大気の中で速く飛べば、そのぶん機体が熱くなる (`HEAT`)。

### 4.4 視点
`V` で **コックピット** と **追従** (機体の後ろから見る) を切り替える。右ドラッグで見回せる。
追従カメラの距離と揺れの大きさは設定で変えられる (9章)。

## 5. 遠くへ行く

### 5.1 行き先を選ぶ
- `M` で **星図** を開く。開いている間はゲームが止まる。
  - 左の欄: 今の星系の天体 (恒星に近い順、衛星は親の下)。
  - 右の欄: 25 光年以内の恒星 (近い順に最大 40 個)。恒星の種類・惑星の数・スウォームや都市惑星があるかが分かる。上から見た図もつく。
  - 「行き先にする」を押すと行き先になる。同じものをもう一度押すと解除。
  - `M` か `Esc` で閉じる。
- `B` を押すたびに、今の星系の天体 (惑星・衛星・小惑星帯・ダイソン・スウォーム・オニール・シリンダー) が近い順に行き先になる。
- 行き先が決まると、HUD に目印・距離・到着までの時間が出る。

### 5.2 巡航 (`J`)
- 天体から遠いほど速く飛べるモード。速さは「いちばん近い天体 (惑星の地表・恒星の表面・シリンダーの外壁) までの距離」で決まり、上限はない。
  - 天体のすぐ近くでも通常の 5 倍 (2,000 m/s) は出る。
  - 全開で、惑星の間が約 1 分、恒星の間 (5 光年) が約 2 分。ブーストを押し続けると、それぞれ約 25 秒、約 40 秒。
- 天体に近づくと自動で減速するので、行き先に向けて全開にしておけばよい。
- 巡航に入るとフライトアシストが ON になり、着陸装置はしまわれる。
- 巡航中は撃てない。地上にいるときと、オニール・シリンダーの中では巡航に入れない。
- `J` でやめると、約 2.5 秒かけて 400 m/s まで減速する (`MODE CRUISE END`)。減速の途中でもう一度 `J` を押すと巡航に戻る。
- 巡航中に `Z` を押すと、減速し終わってからフライトアシストが切れる。
- 巡航中に `G` で脚を出すと巡航が終わる。
- 恒星の間を飛んでいると、途中で行き先の恒星の方が近くなり、「〜星系の圏内に入った」と出てその星系に切り替わる。

### 5.3 ジャンプ (`K`)
- 行き先が **別の恒星** のときに使える。星図で恒星を選んでから `K` を押す。
- 4 秒の充填の後、行き先の恒星から約 1 天文単位 (明るい星ほど遠く) の、元いた星系の側に出る。到着したときは恒星の方を向いて止まっている。
- 充填の途中で `K` をもう一度押すか、行き先を変えると中止になる。
- 惑星の近く (惑星の座標系に入っている間) では使えない。
- ジャンプすると、まわりの敵はいなくなる。

## 6. 着陸と離陸

### 6.1 基本
1. `G` で着陸装置を出す (出し入れに約 1.6 秒)。
2. 毎秒 7 m 以下の降下率で接地する。これより速いと機体が傷む。脚を出さずに機体で接地しても傷む。
3. 3本の脚で接地して止まると、HUD に `LANDED` が出る。

降り方は2通りある。
- **ホバーで垂直に降りる**: `H` でホバーにし、`F` で降りる。手を離すと空中で止まる。
- **滑走して降りる**: AERO のまま、失速しない速さで進入して接地する。スロットルを絞るとブレーキがかかる。

**着陸の補助**: 脚を出して降下していると、地面の近くでは降下の速さが自動で抑えられる
(高度 100 m で毎秒 15 m、20 m 以下で毎秒 3 m まで)。
止まっている機体は、約 35° までの斜面なら滑り出さない。

離陸するときは、ホバーなら `R` で上昇、AERO ならスロットルを上げて滑走する。
地上では巡航に入れないので、浮いてから `J` を押す。

### 6.2 大気のない天体
月や小さな衛星にも降りられる。`G` で脚を出し、`F` で降りれば着陸の補助が働く。

### 6.3 都市惑星のビルの屋上
都市惑星では、地表から 7 km 以内にビルが立つ (超高層ビルは 600 m 級)。ビルには当たり判定があり、屋上に着陸できる。
都市惑星は必ず哨戒隊に守られている。

### 6.4 降りられない場所
- **ガス巨星**: 地面がない。深く潜る (海面の高さから 40 km 未満) と、気圧で機体がつぶされていく。
- **恒星**: 恒星の半径の 1.6 倍より近づくと、機体が焼けていく。

### 6.5 オニール・シリンダー
半径 4 km、長さ 32 km の円筒形の居住地。2本1組で置かれている。

- **入り方**: 円筒の、恒星と反対側 (影の側) の端の軸上に、**入港口の筒** (半径 420 m、長さ 1.4 km) が突き出している。
  この筒に入ると「〜に入港した」と出て、円筒の中に入る。出るときは、同じ筒の外の端から出る。
- **中の重力**: 軸から外向き (円筒の内壁の方) が「下」。地面で 1 G、軸に近づくほど弱くなり、軸の上ではほぼ浮く。
  HUD の下に、軸までの距離とその場所の重力が出る。
- **地面**: 内壁は陸の帯3本と窓の帯3本が交互に並ぶ。どちらにも着陸できる。陸の帯には丘・湖・川・町 (家が立つ)・森がある。
  両端の蓋の前は段々畑の山 (1,100 m)。両端の蓋は壁で、ぶつかると傷む。
- **昼と夜**: 窓の外の鏡の開き方で、24 分ごとに昼と夜が巡る。夜は町と家の窓に明かりが灯る。
- **宇宙港**: 入港口の側の端から 4.2 km の所に、半径 320 m の平らな着陸パッドがある。中に入ると行き先が自動で宇宙港になる。
- **安全地帯**: 中では敵が現れず、増援も呼べない。巡航も使えない。
- **外の当たり判定**: 外壁・鏡・骨組み・入港口の筒にはぶつかる。巡航で近づくと外壁までの距離に応じて減速する。

## 7. 戦闘

敵の出現は設定で OFF にできる (9章)。OFF にすると敵は現れない。

### 7.1 敵
| 敵 | 特徴 |
|---|---|
| RAIDER (軽戦闘機) | 自機と同じ飛び方。守りが薄く、ミサイルを持たない |
| GUNSHIP (重戦闘機) | 遅くて曲がりにくいが硬い。ミサイルを撃つ |

- 敵は星系ごとに決まった場所で **哨戒隊** として待っている (HUD の赤い三角 `HOSTILES`)。
  近づく (小惑星帯では 30 km 以内、惑星の上空では 40 km 以内) と現れる。
  出発地の SOL 星系では、小惑星帯と TERRA の上空 (北緯 20°・東経 30°・高度 5 km) にいる。
- 現れた敵は、5 km 以内に近づくか、自分か近くの仲間が撃たれると襲ってくる。
- 出発地から遠い星系ほど、哨戒隊の数が増え、重戦闘機が混ざりやすい。
- 敵は巡航を使わない。60 km 以上離れると引っ込む (哨戒隊の生き残りは、次に近づいたときにまた現れる)。
- 一度にいる敵は最大 8 機。
- `N` で自機の前方 5〜7 km 先に **増援** を呼べる。呼ぶたびに数が増え (最大 4 機)、3回に1回は重戦闘機が混ざる。

### 7.2 的を選ぶ・ロックオン
- `T` で機首にいちばん近い敵、`Y` で今の的の次に近い敵を的にする。的がいないときは、10 km 以内の敵が自動で選ばれる。
- 的を機首から 25° 以内・5 km 以内に 1.5 秒捉え続けると **ロックオン** になる (的の名前の横に `LOCK`)。

### 7.3 機関砲 (左クリック)
- 毎秒 10 発。弾は実体として飛ぶ (弾速 1,800 m/s に機体の速さが加わる。約 1.4 秒で消えるので、届くのは約 2.5 km まで)。
- 的の **見越し点** (緑の丸) に機首の十字を重ねて撃つ。見越し点が機首から 2° 以内なら、砲が自動でそちらへ向く。
- 撃つと `GUN` のエネルギーが減り、撃たなければ回復する。空になると撃てない。

### 7.4 ミサイル (`Space`)
- ロックオンしてから撃つ。6 発。撃ってから 1 秒たつと次を撃てる。
- 敵のミサイルに狙われると `MISSILE` が点滅する。

### 7.5 守り
- **シールド** (`SHLD`) が先に攻撃を受け止める。4 秒被弾しなければ、毎秒 12 ずつ回復する。被弾すると画面の縁が青く光る。
- シールドを抜けた攻撃は **機体** (`HULL`) に届く。機体は自然には回復しない (8章)。

## 8. 損傷・回復・復帰

### 8.1 機体が傷む原因
- 敵の攻撃 (シールドを抜けた分)
- 速すぎる接地 (毎秒 7 m 超)、脚を出さない接地、地面を擦りながら滑る
- 空力加熱 (`HEAT` 100% 超)
- ダイソン・スウォームのパネル、オニール・シリンダーの外の部品や中の蓋への、毎秒 15 m を超える衝突
- 恒星に近づきすぎる、ガス巨星に深く潜る

### 8.2 回復
- **シールド**: 4 秒被弾しなければ自然に回復する。
- **機体とミサイル**: 着陸して (`LANDED`) 3 秒止まっていると、修理が始まる (毎秒 25%)。
  機体が満タンになるとミサイルも補給され、「修理・補給が完了した」と出る。

### 8.3 機体を失ったとき
`HULL` が 0 になると機体を失い、約 3.5 秒後に復帰する。機体・シールド・弾薬はすべて元に戻る。

| 失った場所 | 復帰する場所 |
|---|---|
| 惑星の近く | その場所の 300 m 上空 (ホバーで止まった状態) |
| ガス巨星 | 大気の上端より 60 km 上 |
| オニール・シリンダーの中 | 宇宙港の上空 |
| 宇宙 | その場所。恒星の近くなら、恒星の半径の 6 倍まで離される |

## 10. 行ける場所の案内

### 10.1 出発地 SOL 星系
太陽系に似せて手で配置した星系。名前はラテン語。軌道半径は本物と同じ天文単位で、大きさは TERRA (半径 400 km) を基準にした比率。
設定の「惑星の大きさ」を「実寸」にすると、本物の大きさになる (TERRA 半径 6,371 km・自転 23.9 時間、月まで 384,400 km、
木星 半径 69,911 km・自転 9.9 時間、PHOBOS 半径 11 km)。開始位置から TERRA までは、半径との比がゲーム用と同じ (約 8.4 倍) なので、
見かけの大きさは変わらない。地表を飛んで一周するのには、ゲーム用の 16 倍の時間がかかる。

- 惑星: MERCURIUS, VENUS, TERRA, MARS, IUPPITER, SATURNUS, URANUS, NEPTUNUS
- 主な衛星: LUNA (TERRA)、PHOBOS・DEIMOS (MARS)、IO・EUROPA・GANYMEDES・CALLISTO (IUPPITER)、TITAN (SATURNUS)、TRITON (NEPTUNUS)
- SATURNUS には環がある (当たり判定なし)。
- TERRA のラグランジュ点 L5 に、オニール・シリンダー `INSULA I / II` がある。開始位置から巡航で約 1 分。

### 10.2 ほかの星系
宇宙は区画ごとに自動で作られ、どこまで行っても続く。同じ場所には必ず同じ星がある。

- 惑星は6種類: 海洋 (地球型)・砂漠・氷・溶岩・岩石・ガス巨星。ガス巨星は衛星を持ちやすい。
- 小惑星帯がある星系もある。
- 約 15% の星系では、住みやすい惑星の1つが **都市惑星** (エキュメノポリス) になっている。陸は街に覆われ、夜側は街明かりで光る。
  その星系では、都市惑星のラグランジュ点 L4 か L5 にオニール・シリンダーが1組ある。
- 約 12% の星系は **ダイソン・スウォーム** に囲まれている。傾きの違う何本もの帯に、六角形の集光パネル (1枚の半径が数十万 km) が
  数千〜1万枚並ぶ。恒星側の面は太陽電池、裏は排熱板で鈍く赤く光る。外から見ると恒星は暗く赤くなる。
  パネルにはぶつかる。星図や `B` で行き先にすると、いちばん近いパネルの手前へ案内される。
