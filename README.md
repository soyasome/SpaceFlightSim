# STARWAKE

Webブラウザで動く宇宙フライトシミュレーター。ビルド不要 (素の ES モジュール + Three.js)。

## 起動

```
python serve.py
```

ブラウザで http://localhost:5173/ を開く。Three.js を CDN から読み込むためネット接続が必要。

単体テスト: http://localhost:5173/tests.html

技術解説 (内部のアルゴリズムの説明、図と動かせるデモつき): http://localhost:5173/docs/

## 進捗

- [x] M1 宇宙飛行の基盤 (6自由度・フライトアシスト・視点切り替え・Floating Origin)
- [x] M2 惑星と大気の描画 (キューブ球の四分木LOD・Worker生成・大気散乱・惑星回転座標系)
- [x] M3 大気中の飛行と着陸 (重力・揚力/抗力/失速・ホバー・着陸装置・空力加熱・損傷・HUD計器・効果音)
- [x] M4 ドッグファイト (機関砲・ミサイル・シールド・ロックオン・見越し点・レーダー・敵AI・哨戒隊と増援)
- [x] M5 無限の宇宙 (自動生成の銀河と星系・惑星6種類・恒星間の巡航・ジャンプ・星図)

## 構成

- `src/core` ゲームループ、入力
- `src/physics` 剛体
- `src/flight` 機体と操縦系 (`shipParams.js` に調整値)、空力 (`aero.js`)、接地 (`ground.js`。接触点ごとに真下の地面を調べるので、崖の壁にも当たる)
- `src/audio` 効果音 (Web Audio で合成)
- `src/combat` 戦闘 (`combat.js` 全体の管理、`ai.js` 敵の操縦、`projectiles.js` 弾とミサイル、`targeting.js` 見越し計算、`effects.js` 演出)
- `src/universe` 銀河 (`galaxy.js`)、星系 (`system.js`)、ダイソン・スウォーム (`swarm.js`)、オニール・シリンダー (`habitat.js`) の生成。three.js に依存しない
- `src/camera` 視点
- `src/render` 星空、塵、小惑星、機体モデル、ダイソン・スウォーム (`swarm.js`)、オニール・シリンダーの外観 (`habitat.js`)
- `src/terrain` 地形 (ノイズ、標高関数、チャンク生成、Worker)。three.js に依存しない。
  標高関数 (`terrainFn.js`) にはドメインワープ・侵食風ノイズ・クレーター・段のある渓谷・崖で囲まれた台地 (メサ) が入っている。
  渓谷と台地の種類ごとの設定は `CLIFFS`
- `src/planet` 惑星、LOD、大気シェーダー (地面の細かい凹凸と水面、都市惑星の道路と夜景もここ)、地表に散らばる岩と木 (`scatter.js`。当たり判定なし。木は 350 m より遠くをビルボードで 3 km 先まで描く)、
  都市惑星の街区 (`city.js`。敷地ごとのビルを決め、描画と当たり判定の両方がこれを使う)
- `src/ui` HUD
- `tests` ブラウザで動く単体テスト

## 飛び方 (M3)

フライトアシスト ON のとき、操縦の仕方は場所で変わる (HUD の `MODE`)。

| MODE | 場所 | スロットル | 手を離すと |
|---|---|---|---|
| SPACE | 宇宙・薄い大気 (高度 約32km以上) | 目標速度 | 止まる (重力も打ち消す) |
| AERO | 大気中 | 推力 | 翼の揚力で飛び続ける。約70 m/s を下回ると失速 |
| HOVER | 大気中で `H` | 目標速度 (低速) | 空中で止まる。`R`/`F` で上昇・下降 |
| CRUISE | `J` | 目標速度 × 高度による倍率 | 重力と空気を無視する。解除すると約2.5秒かけて 400 m/s まで減速する |

着陸: `G` で脚を出し、降下率 7 m/s 以下で接地する。`H` のホバーで垂直に降りても、滑走して降りてもよい。
脚を出さない接地、速すぎる接地、空力加熱 (HEAT 100% 超) で機体が損傷し、HULL が 0 になると上空で復帰する。

## 宇宙 (M5)

- **銀河**: 空間を 10 光年四方の区画に分け、区画の番号から乱数の種を作って恒星を 0〜3 個置く
  (`src/universe/galaxy.js`)。どこまで行っても続き、同じ場所には必ず同じ星がある。保存はしない。
- **星系**: 恒星の種から、惑星 (海洋・砂漠・氷・溶岩・岩石・ガス巨星)、衛星、小惑星帯、敵の哨戒隊を決める。
  約15%の星系では、住みやすい惑星が1つ**都市惑星** (エキュメノポリス) になる。陸は街に覆われ、夜側は街明かりで光る。
  地表から 7 km 以内ではビルが立ち (超高層ビルは 600 m 級)、ビルには当たり判定があるので屋上に着陸できる。
  都市惑星は必ず哨戒隊に守られている。
  約12%の星系は**ダイソン・スウォーム**に囲まれている。傾きの違う何本もの帯に、六角形の集光パネル
  (1枚の半径が数十万 km) が数千〜1万枚並ぶ。表 (恒星側) は太陽電池、裏は排熱板で鈍く赤く光る。
  外から見ると恒星は暗く赤くなり (遠くの星空でも分かる)、外側の惑星に届く光も弱まる。
  パネルには当たり判定がある。星図で行き先にできる。
  **オニール・シリンダー** (半径 4 km、長さ 32 km の円筒の居住地) が2本1組で、出発地 SOL の TERRA の L5 (`INSULA I / II`) と、
  都市惑星の L4 か L5 にある。軸は恒星を向き、窓の外の鏡が花びらのように開く。2本は逆向きに回って見える
  (回っているのは見た目だけ)。外壁には当たり判定があり、巡航は外壁に近づくと減速する。
  影の側の端の軸上にある入港口の筒から中に入れる。中は回らない座標系で、重力は軸から外向きに g · r / R
  (地面で 1 g、軸の近くでは浮く)。陸の帯と窓の帯のどちらにも着陸でき、両端の蓋は壁。中は安全地帯で、巡航と増援は使えない
  (設計と今後の段階: `docs/design-oneill-cylinder.md`)
  (`src/universe/system.js`)。出発地の SOL 星系だけは太陽系に似せて手で配置してある
  (名前はラテン語: MERCURIUS, VENUS, TERRA, MARS, IUPPITER, SATURNUS, URANUS, NEPTUNUS と主な衛星)。
  軌道半径は本物と同じ天文単位、大きさは TERRA (半径 400 km) を基準にした比率。土星には環がある (当たり判定なし)。
- **座標**: 天体の位置は「星系座標」(恒星が原点) で持つ。機体は「世界座標」で動かし、その原点を
  機体に合わせて動かす (`game.origin`)。別の恒星の方が近くなったら、その星系の座標に乗り換える。
  こうすると何光年飛んでも機体の座標は小さいままで、動きが粗くならない。
- **巡航の速度則** (`src/flight/cruise.js`): 速さ = いちばん近い天体までの距離で決まる倍率 × 400 m/s。
  上限はない。全開で惑星間が約 2 分、恒星間 (5 光年) が約 3.5 分。調整はこのファイルの 4 つの数字。
- **行き先**: `M` で星図を開いて選ぶか、`B` で今の星系の天体を近い順に切り替える。
  HUD に目印・距離・到着予想が出る。
- **ジャンプ**: 行き先が別の恒星のとき `K`。4 秒の充填の後、その恒星から約 1 天文単位の位置に出る。
  惑星のすぐ近く (座標系が惑星に切り替わっている間) では使えない。
- **着陸の補助**: 着陸装置を出していると、地面の近くで降下が自動的に抑えられる (20m 以下で毎秒 3m)。
  大気のない天体でも、`G` で脚を出して `F` で降りれば着陸できる。
- ガス巨星には降りられない (深く潜ると気圧でつぶれる)。恒星に近づきすぎると焼ける。

## 戦闘 (M4)

- 敵も自機と同じ飛行モデル (`Ship`) で飛ぶ。AI (`src/combat/ai.js`) は人間と同じ操縦入力を出すだけ。
- 敵の哨戒隊は星系ごとに決まる。出発地では小惑星帯と TERRA 上空 (北緯20°・東経30°) にいる。HUD の赤い三角 `HOSTILES` が目印。
  5km 以内に近づくか、撃つと襲ってくる。`N` で自機の前方に増援を呼べる (最大8機)。
- 機関砲 (左クリック): 弾は実体として飛ぶ。ロック中の敵の見越し点 (緑の丸) に機首の十字を重ねて撃つ。
  見越し点が機首から 2° 以内なら、砲が自動でそちらへ向く (`shipParams.js` の `gunGimbal`)。
- ミサイル (`Space`): 的を機首から 25° 以内・5km 以内に 1.5 秒捉えるとロックオン。6発。
- シールドは 4 秒被弾しなければ回復する。機体 (HULL) とミサイルは、着陸して 3 秒止まると回復する。
- 巡航中は撃てない。敵は巡航を使わず、60km 離れると引っ込む (哨戒隊の生き残りは次回また現れる)。
- 設定の「敵の出現」を OFF にすると敵が現れない。

武器・耐久・敵機の数値は `src/flight/shipParams.js` (`weapons`, `RAIDER`, `GUNSHIP`)、
敵の腕前や判断は `src/combat/ai.js`、哨戒隊の構成は `src/combat/combat.js` の `zones`。

## 設定

プレイ中に `Tab` (または右上のボタン、`Esc`) で操作方法と設定のメニューを開ける。開いている間は一時停止する。
設定値はブラウザの localStorage に保存される。項目の追加は `src/core/settings.js` の `SETTING_DEFS` に1行足すだけでよい。

## デバッグ

ブラウザのコンソールで:

- `debug.goto(高度m, 緯度, 経度, 機首角, 速度)` 惑星の上空へ瞬間移動。速度 0 (省略時) はホバーで静止、
  0 より大きいと飛行状態 (例: `debug.goto(1000, 35, 100, 0, 200)`)
- `debug.repair()` 機体・シールド・弾薬を回復
- `debug.spawn(数, 'raider' | 'gunship', 距離m)` 敵を自機の前方に出す、`debug.clearEnemies()` 敵をすべて消す
- `debug.space(x, y, z)` 宇宙の指定位置へ、`debug.stop()`、`debug.state()`
- `debug.system()` 今の星系の天体一覧、`debug.stars()` 近くの恒星の一覧
- `debug.near(番号, 半径の倍数)` 天体の近くの宇宙へ、`debug.goto(高度, 緯度, 経度, 機首角, 速度, 番号)` 天体の上空へ
- `debug.jumpTo(n)` 近い順で n 番目の恒星へ即ジャンプ
